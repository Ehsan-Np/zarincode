# 💰 مدل درآمدی زرین کد

> **سند راهبردی درآمد** — نسخه ۱.۰
> بر اساس بررسی کامل پروژه (قالب وردپرس زرین کد) و هم‌راستا با قابلیت‌های موجود در قالب.

---

## ۱. تحلیل کامل پروژه (زیرساخت درآمدی موجود)

بررسی دقیق کد قالب نشان می‌دهد زرین کد یک **پلتفرم چندکاناله** است که زیرساخت چندین مدل درآمدی را از قبل دارد. این یک مزیت بزرگ است؛ بخش بزرگی از کار، «فعال‌سازی و بهینه‌سازی» است نه «ساخت از صفر».

### امکانات درآمدزایی که از قبل در قالب هست ✅

| ماژول | قابلیت | کاربرد درآمدی |
|--------|--------|--------------|
| `course.php` | LMS کامل (دوره، سرفصل، جلسه، پیشرفت، گواهی) | فروش دوره آموزشی |
| `wallet.php` | کیف پول + تراکنش + برداشت | اعتبار، بازگشت وجه، ذخیره خرید |
| `coupons.php` | کد تخفیف + امکان چندکد هم‌زمان | تخفیف، آپسل، کمپین |
| `rewards.php` | پاداش/کد تخفیف اختصاصی + اتصال به ربات | بازاریابی دهان‌به‌دهان |
| `zarinpal.php` | درگاه زرین‌پال | پرداخت آنلاین امن |
| `contracts.php` + `contract-payments.php` | قرارداد آنلاین + **پرداخت مرحله‌ای** | پروژه‌های آژانسی با پیش‌پرداخت |
| `booking.php` | رزرو نوبت (مشاوره) | فروش جلسه مشاوره پولی |
| `services.php` | خدمات + بسته‌های قیمتی ۳ سطحی | فروش خدمات (آژانس) |
| `telegram.php` / `bale.php` / `messenger-bot.php` | ربات تلگرام/بله، ارسال خودکار، اعلان شخصی | فروش در پیام‌رسان، اشتراک VIP |
| `sms-kavenegar.php` + `sms-campaigns.php` | پیامک + کارزار (campaign) + یادآوری رها کردن سبد | بازیابی فروش |
| `accounting.php` | حسابداری + گزارش مالی + CSV | مدیریت سودآوری |
| `user-panel.php` | پنل جامع ۱۹ بخشی | تجربه خرید، وفاداری |
| `announcements.php` | اطلاع‌رسانی هدفمند | فروش مجدد |
| `ticket.php` | تیکتینگ | پشتیبانی پولی / رضایت |
| `notification.php` | سیستم اعلان | بازگشت کاربر |
| WooCommerce | فروشگاه کامل + محصولات دیجیتال | فروش قالب/افزونه/فونت/سورس‌کد |

### زیرساخت‌های درآمدی افزوده‌شده در نسخه ۳.۳۶ ✅
1. **پلن اشتراک (Membership)** با تمدید، ارتقا، تنزل، هدیه و محدودیت دانلود
2. **مسیر یادگیری / Bundle** با ثبت‌نام یک‌جای دوره‌ها پس از خرید محصول مرتبط
3. **استعلام عمومی گواهینامه** و API اعتبارسنجی
4. **لایسنس محصولات دیجیتال** با محدودیت دامنه و تاریخ انقضا
5. **برنامه همکاری در فروش (Affiliate)** با دوره اطمینان و تسویه کیف پول

### شکاف‌های تجاری باقی‌مانده
1. شارژ خودکار دوره‌ای فقط در صورت ارائه توکن پرداخت recurring توسط درگاه قابل اجراست؛ فعلاً یادآوری و لینک تمدید ارائه می‌شود.
2. فروش کاملاً درون‌رباتی بدون بازکردن checkout هنوز نیازمند قرارداد API پرداخت پیام‌رسان است.
3. اعتبار حقوقی گواهینامه به مجوزهای تجاری مجموعه وابسته است، نه صرفاً قابلیت فنی استعلام.

## ۲. پنج کانال اصلی درآمد

### کانال A — آموزش (آکادمی) 🎓
**ماهیت:** یک‌بار تولید، فروش مکرر → پایدارترین درآمد.

**مدل‌های قیمت‌گذاری:**
- **تک‌دوره:** ۱٬۰۰۰٬۰۰۰ تا ۳٬۵۰۰٬۰۰۰ تومان
- **سه سطح هر دوره:**
  - پایه: فقط ویدیو (ارزان)
  - حرفه‌ای: ویدیو + پشتیبانی + فایل پروژه
  - مربی: + جلسه خصوصی آنلاین
- **بسته ترکیبی (پیشنهاد):** «مسیر استخدام لاراول» = ۳ دوره + پروژه پایانی + گواهی → با ۲۰٪ تخفیف

**راهکارهای افزایش درآمد:**
- تخفیف زودهنگام (Early Bird) و فصلی — بازار ایران به تخفیف واقعی حساس است
- ضمانت بازگشت وجه (قالب دارد) → افزایش نرخ تبدیل
- **گواهی پولی با کد استعلام** — انگیزه قوی در ایران
- دوره‌های «آمادگی مصاحبه» و «پروژه پایانی» → دوره‌های کم‌هزینه اما پرتقاضا

---

### کانال B — فروشگاه محصولات دیجیتال 🛒
**ماهیت:** حاشیه سود ~۱۰۰٪ (فایل دیجیتال) → پرسودترین نسبت به زمان.

**محصولات:**
- قالب وردپرس: ۴۹۰٬۰۰۰ تا ۱٬۲۹۰٬۰۰۰ تومان
- افزونه (مخصوص نیاز ایران: درگاه، ربات تلگرام، کیف پول): ۳۹۰٬۰۰۰ تا ۸۹۰٬۰۰۰ تومان
- سورس‌کد آماده: ۸۹۰٬۰۰۰ تا ۲٬۴۹۰٬۰۰۰ تومان
- فونت فارسی حرفه‌ای: ۱۵۰٬۰۰۰ تا ۵۰۰٬۰۰۰ تومان

**راهکارها:**
- **آپسل و فروش متقابل:** بعد از خرید دوره → محصولات مرتبط پیشنهاد شود
- افزونه‌های اختصاصی ایرانی (جای خالی بزرگ — خیلی از افزونه‌های خارجی با ایران ناسازگارند)
- لایسنس یک‌بار / چنددامنه (قالب زیرساخت ندارد → فرصت)
- کیف پول و اعتبار → کاربران راحت‌تر خرید می‌کنند

---

### کانال C — خدمات و پروژه (آژانس) 🛠️
**ماهیت:** درآمد بالا ولی وابسته به ظرفیت تیم → بهتر است با Retainer تکرارشونده شود.

**خدمات (بسته‌های ۳ سطحی — قالب دارد):**
- طراحی سایت: پایه ۱۵M / حرفه‌ای ۳۲M / سازمانی ۶۸M تومان
- اپلیکیشن اندروید: ۴۵M تومان
- سئو ماهانه: ۸M–۱۴M تومان
- پشتیبانی ماهانه (Retainer): ۳M–۶٫۵M تومان

**راهکارها:**
- **مشاوره ۶۰ دقیقه پولی** به‌عنوان «نقطه ورود» → سپس آپسل به پروژه کامل
- **قرارداد + پرداخت مرحله‌ای** (قالب دارد) → اعتماد و تعهد
- **نگهداری ماهانه (Retainer):** مهم‌ترین مدل B2B برای درآمد پیش‌بینی‌پذیر
- نمونه‌کار واقعی → اعتمادسازی برای پروژه‌های بزرگ‌تر

---

### کانال D — ربات تلگرام/بله و پیام‌رسان 🤖 (خاص ایران)
**ماهیت:** دسترسی مستقیم به مخاطب؛ در ایران بسیار پرقدرت.

**راهکارها:**
- **فروش خودکار از طریق ربات:** خرید دوره/محصول بدون ورود به سایت
- **اشتراک پولی کانال VIP:** محتوای اختصاصی با حق عضویت ماهانه
- **اعلان و کد تخفیف شخصی** (قالب دارد) → افزایش بازخرید
- **یادآوری رهاکردن سبد** از طریق پیامک/ربات (قالب زیرساخت دارد)

---

### کانال E — تبلیغات و همکاری (Affiliate) 📣
**ماهیت:** درآمد منفعل، کم‌هزینه.

**راهکارها:**
- همکاری با هاست/دامنه ایرانی → کمیسیون معرفی
- همکاری با شرکت‌های نرم‌افزاری → معرفی متقابل
- تبلیغات هدفمند به مخاطبان سایت
- (Google AdSense در ایران محدود است → تمرکز روی همکاری مستقیم)

## ۳. فرمول پیشنهادی استراتژی درآمد

**استراتژی پیشنهادی: «آکادمی + فروشگاه + خدمات» با تمرکز روی ۲ محرک رشد:**

```
درآمد = آموزش (تکرارشونده) + محصولات دیجیتال (حاشیه بالا) + نگهداری سایت (پیش‌بینی‌پذیر)
```

**قیف فروش (Funnel):**
1. **جذب:** محتوای رایگان (آموزش رایگان، مجله، ربات)
2. **نقطه ورود:** مشاوره رایگان / دوره ارزان
3. **اولین خرید:** دوره مقدماتی / محصول کوچک
4. **آپسل:** دوره پیشرفته / بسته / محصول پرسود
5. **تکرار:** اشتراک ماهانه / نگهداری سایت / کد تخفیف شخصی

## ۴. تخمین درآمد (محافظه‌کارانه، ماهانه)

| کانال | سناریوی کم | سناریوی متوسط |
|-------|-----------|--------------|
| فروش دوره | ۳۰×۲M = ۶۰M | ۸۰×۲٫۵M = ۲۰۰M |
| فروشگاه دیجیتال | ۲۰×۱M = ۲۰M | ۵۰×۱٫۵M = ۷۵M |
| خدمات/نگهداری | ۵×۳M = ۱۵M | ۱۲×۵M = ۶۰M |
| مشاوره | ۱۰×۰٫۵M = ۵M | ۲۵×۰٫۸M = ۲۰M |
| اشتراک ماهانه (جدید) | ۵۰×۰٫۸M = ۴۰M | ۲۰۰×۱M = ۲۰۰M |
| **جمع تقریبی** | **~۱۴۰M تومان** | **~۵۵۵M تومان** |

## ۵. اولویت اجرا (Roadmap پیشنهادی)

### فاز ۱ — فعال‌سازی سریع (کم‌هزینه، هفته ۱)
- فعال‌کردن کامل کیف پول، کد تخفیف، پاداش ربات، درگاه زرین‌پال
- تنظیم بسته‌های قیمتی خدمات و رزرو مشاوره
- راه‌اندازی ربات تلگرام/بله و اعلان‌ها
- تنظیم کارزارهای پیامکی (جشنواره، بازیابی سبد)

### فاز ۲ — رشد (۲-۶ هفته)
- **افزودن پلن اشتراک ماهانه** (بزرگ‌ترین جهش — گزینه با بیشترین بازده)
- **بسته‌ها و مسیرهای آموزشی** با گواهی مشترک
- **گواهی پولی** با کد استعلام آنلاین
- برنامه همکاری (Affiliate) با هاست/محصولات

### فاز ۳ — مقیاس (۲-۳ ماه)
- فروش خودکار از طریق ربات
- اشتراک نگهداری سایت خودکار و تمدیدشونده
- تحلیل داده فروش و بهینه‌سازی قیمت‌گذاری

---

## ۶. ریسک‌ها و ملاحظات (بازار ایران)

- **وابستگی به درگاه پرداخت:** درگاه زرین‌پال باید فعال و تست شود؛ گواهی SSL و نماد اعتماد الکترونیکی (اینماد) برای اعتماد ضروری است
- **نوسان تورم:** قیمت‌ها باید قابل‌به‌روزرسانی باشند (قالب این امکان را دارد)
- **رعایت قوانین:** محتوای آموزشی، قراردادها و فروشگاه باید مطابق **قانون تجارت الکترونیکی**، **قانون جرایم رایانه‌ای (پلیس فتا)** و مقررات **مالیات/تأمین اجتماعی** باشد — مستندات حقوقی در قالب موجود است
- **اعتماد مشتری:** ضمانت بازگشت وجه، گواهی و پشتیبانی پاسخگو کلید موفقیت است
