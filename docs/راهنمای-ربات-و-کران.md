## ۱. ساخت ربات تلگرام

۱. در تلگرام، ربات **@BotFather** را باز کنید.
۲. دستور `/newbot` را بفرستید.
۳. یک نام نمایشی وارد کنید. مثال: `زرین کد`
۴. یک نام کاربری وارد کنید که حتماً به `bot` ختم شود. مثال: `ZarincodeBot`
۵. BotFather یک **توکن** به شما می‌دهد؛ چیزی شبیه:

```
7123456789:AAFtR3xK9pLmN2qW5vB8cD1eF4gH6jK0lMn
```

> ⚠️ این توکن مانند رمز عبور است. آن را در اختیار کسی قرار ندهید.

### تنظیمات پیشنهادی ربات (اختیاری ولی مفید)

در همان BotFather:

- `/setdescription` — توضیح ربات
- `/setabouttext` — درباره ربات
- `/setuserpic` — لوگوی ربات
- `/setcommands` — تعریف دستورها؛ متن زیر را بفرستید:

```
start - اتصال حساب کاربری
stop - قطع دریافت اعلان‌ها
help - راهنمای ربات
```

## ۲. ساخت ربات بله

بله (Bale) پیام‌رسان ایرانی است و API آن تقریباً مشابه تلگرام است.

۱. وارد [https://ble.ir](https://ble.ir) شوید و ربات **@BotFather** بله را باز کنید.
۲. دستور `/newbot` را بفرستید.
۳. نام و نام کاربری ربات را وارد کنید.
۴. توکن دریافتی را کپی کنید.

> 💡 مزیت بله: بدون فیلتر و با سرعت بالا در ایران کار می‌کند؛ برای کاربران ایرانی گزینه‌ی مطمئن‌تری است.

## ۳. تنظیمات در پیشخوان وردپرس

به مسیر زیر بروید:

```
پیشخوان → زرین کد → تنظیمات قالب → تلگرام و بله
```

فیلدهای زیر را پر کنید:

| فیلد | توضیح | نمونه |
|---|---|---|
| فعال‌سازی تلگرام | روشن کنید | ✅ |
| توکن ربات تلگرام | توکن BotFather | `7123456789:AAF...` |
| آیدی کانال/گروه | برای ارسال خودکار مطالب به کانال | `@zarincode` |
| نام کاربری ربات تلگرام | بدون `@` | `ZarincodeBot` |
| فعال‌سازی بله | روشن کنید | ✅ |
| توکن ربات بله | توکن ربات بله | `1234:AAG...` |
| نام کاربری ربات بله | بدون `@` | `ZarincodeBot` |
| کلید امنیتی وب‌هوک | یک رشته تصادفی | `k7Xm2Pq9Rt4Wz` |
| آیدی چت مدیر | برای دریافت اعلان درخواست پروژه | `123456789` |
| کلید کران خارجی | یک رشته تصادفی | `cronKey8823` |

### چطور «آیدی چت مدیر» را پیدا کنم؟

۱. ربات **@userinfobot** را در تلگرام باز کنید.
۲. دستور `/start` را بفرستید.
۳. عددی که نمایش می‌دهد (مثلاً `123456789`) آیدی چت شماست.

> برای دریافت اعلان در کانال، ابتدا ربات را ادمین کانال کنید و آیدی کانال را با `@` وارد کنید.

## ۴. ثبت وب‌هوک

وب‌هوک باعث می‌شود پیام‌های ارسالی به ربات، بلافاصله به سایت شما برسد.

### روش ۱: از پیشخوان (ساده‌ترین راه)

در صفحه‌ی تنظیمات پیام‌رسان‌ها، روی دکمه‌ی **«ثبت خودکار وب‌هوک»** بزنید.

### روش ۲: دستی از طریق مرورگر

آدرس زیر را در مرورگر باز کنید (مقادیر را جایگزین کنید):

**تلگرام:**
```
https://api.telegram.org/botTOKEN/setWebhook?url=https://YOURSITE.ir/wp-json/zarincode/v1/bot/telegram?secret=SECRET
```

**بله:**
```
https://tapi.bale.ai/botTOKEN/setWebhook?url=https://YOURSITE.ir/wp-json/zarincode/v1/bot/bale?secret=SECRET
```

اگر پاسخ زیر را دیدید یعنی موفق بوده:

```json
{"ok":true,"result":true,"description":"Webhook was set"}
```

> ⚠️ **نکته مهم:** وب‌هوک فقط روی سایت‌های دارای **SSL معتبر (https)** کار می‌کند. اگر سایت شما SSL ندارد، از روش کران (بخش بعد) استفاده کنید.

### بررسی وضعیت وب‌هوک

```
https://api.telegram.org/botTOKEN/getWebhookInfo
```

## ۵. تنظیم کران جاب در هاست

کران جاب وظیفه دارد **صف اعلان‌ها** را پردازش کند و **یادآوری نوبت‌ها** را بفرستد.

### چرا کران لازم است؟

وقتی یک دوره یا محصول جدید منتشر می‌کنید، ارسال پیام به هزاران کاربر زمان‌بر است. اگر این کار هنگام انتشار انجام شود، صفحه‌ی مدیریت قفل می‌شود. به همین دلیل اعلان‌ها در صف قرار می‌گیرند و کران آن‌ها را **دسته‌دسته (هر بار ۲۵ کاربر)** ارسال می‌کند.

### آدرس کران شما

```
https://YOURSITE.ir/?zc_cron=CRON_KEY
```

`CRON_KEY` همان مقداری است که در تنظیمات قالب وارد کرده‌اید.

---

### روش الف) سی‌پنل (cPanel)

۱. وارد cPanel شوید.
۲. بخش **Advanced → Cron Jobs** را باز کنید.
۳. در قسمت **Common Settings** گزینه‌ی `Every 5 Minutes` را انتخاب کنید (یا `*/5 * * * *`).
۴. در فیلد **Command** یکی از دستورهای زیر را وارد کنید:

```bash
wget -q -O /dev/null "https://YOURSITE.ir/?zc_cron=CRON_KEY" >/dev/null 2>&1
```

یا اگر `wget` در دسترس نبود:

```bash
curl -s "https://YOURSITE.ir/?zc_cron=CRON_KEY" >/dev/null 2>&1
```

۵. روی **Add New Cron Job** بزنید.

---

### روش ب) دایرکت‌ادمین (DirectAdmin)

۱. وارد DirectAdmin شوید.
۲. **Advanced Features → Cronjobs** را باز کنید.
۳. مقادیر را چنین تنظیم کنید:

| فیلد | مقدار |
|---|---|
| Minute | `*/5` |
| Hour | `*` |
| Day of Month | `*` |
| Month | `*` |
| Day of Week | `*` |

۴. در Command:

```bash
curl -s "https://YOURSITE.ir/?zc_cron=CRON_KEY" >/dev/null 2>&1
```

---

### روش ج) پلسک (Plesk)

۱. **Websites & Domains → Scheduled Tasks** را باز کنید.
۲. **Add Task** را بزنید.
۳. Task type را روی **Fetch a URL** بگذارید.
۴. آدرس کران را وارد کنید.
۵. Run را روی `Cron style` با مقدار `*/5 * * * *` تنظیم کنید.

---

### روش د) سرور اختصاصی (SSH)

```bash
crontab -e
```

سپس این خط را اضافه کنید:

```
*/5 * * * * curl -s "https://YOURSITE.ir/?zc_cron=CRON_KEY" >/dev/null 2>&1
```

---

### روش ه) سرویس رایگان کران آنلاین

اگر هاست شما کران ندارد، می‌توانید از سرویس‌های زیر استفاده کنید:

- [cron-job.org](https://cron-job.org) (رایگان)
- [easycron.com](https://www.easycron.com)

فقط کافی است آدرس کران را وارد کرده و بازه را روی ۵ دقیقه بگذارید.

---

### بهبود کران پیش‌فرض وردپرس (توصیه‌شده)

کران داخلی وردپرس فقط وقتی کسی از سایت بازدید کند اجرا می‌شود. برای دقت بیشتر، آن را خاموش کرده و به کران واقعی هاست بسپارید.

در فایل `wp-config.php`، پیش از خط `/* That's all, stop editing! */` این کد را اضافه کنید:

```php
define( 'DISABLE_WP_CRON', true );
```

سپس یک کران دوم برای خود وردپرس بسازید:

```
*/10 * * * * curl -s "https://YOURSITE.ir/wp-cron.php?doing_wp_cron" >/dev/null 2>&1
```

## ۶. نحوه اتصال کاربران

کاربران این مراحل را طی می‌کنند:

۱. وارد **پنل کاربری → اعلان‌ها و ربات** می‌شوند.
۲. کد اتصال اختصاصی خود را می‌بینند (مثلاً `MNCP0WKG`).
۳. روی دکمه‌ی «اتصال به ربات تلگرام» می‌زنند؛ ربات باز می‌شود.
۴. دستور زیر را می‌فرستند:

```
/start MNCP0WKG
```

۵. ربات پیام تأیید می‌فرستد و از آن پس اعلان‌ها ارسال می‌شود.

### انواع اعلان قابل تنظیم

هر کاربر می‌تواند این موارد را جداگانه روشن/خاموش کند:

- پاسخ به تیکت پشتیبانی
- انتشار دوره‌های جدید
- محصولات تازه فروشگاه
- مقالات و آموزش‌های جدید
- وضعیت سفارش‌ها
- تراکنش‌های کیف پول
- یادآوری نوبت مشاوره
- تخفیف‌ها و پیشنهادهای ویژه

### دستورهای ربات

| دستور | کار |
|---|---|
| `/start کد` | اتصال حساب |
| `/start` | نمایش راهنمای اتصال |
| `/stop` | قطع دریافت اعلان‌ها |
| `/help` | راهنما |

## ۷. عیب‌یابی

### ربات پاسخ نمی‌دهد

۱. توکن را دوباره بررسی کنید (فاصله‌ی اضافی نداشته باشد).
۲. وضعیت وب‌هوک را چک کنید:
   `https://api.telegram.org/botTOKEN/getWebhookInfo`
۳. اگر `last_error_message` مقدار داشت، آن را بخوانید؛ معمولاً مشکل SSL است.

### خطای `SSL certificate problem`

گواهی SSL سایت معتبر نیست. از Let's Encrypt استفاده کنید یا موقتاً روش کران را جایگزین وب‌هوک کنید.

### اعلان‌ها ارسال نمی‌شوند

۱. مطمئن شوید کران تنظیم شده است.
۲. آدرس کران را دستی در مرورگر باز کنید؛ باید چنین پاسخی ببینید:

```json
{"success":true,"data":{"sent":3,"remaining":0}}
```

۳. اگر `403` گرفتید، کلید کران اشتباه است.

### کاربر پیام «کد نامعتبر» می‌گیرد

کد اتصال منقضی یا تازه‌سازی شده است. کاربر باید از پنل، کد جدید بگیرد.

### تلگرام در ایران فیلتر است

سرور شما (هاست) معمولاً به تلگرام دسترسی دارد حتی اگر کاربر نداشته باشد. اگر هاست ایران است و دسترسی ندارد:

- از **بله** استفاده کنید (پیشنهاد ما)
- یا سایت را روی هاست خارج از ایران میزبانی کنید

---

## پرسش‌های متداول

**آیا می‌توانم فقط از بله استفاده کنم؟**
بله. کافی است تلگرام را غیرفعال بگذارید.

**آیا ارسال گروهی محدودیت دارد؟**
تلگرام حدود ۳۰ پیام در ثانیه اجازه می‌دهد. قالب به‌صورت پیش‌فرض هر ۵ دقیقه ۲۵ کاربر را پردازش می‌کند که کاملاً ایمن است. برای تغییر:

```php
add_filter( 'zc_notify_batch_size', function () {
    return 50;
} );
```

**اعلان‌ها در صف می‌مانند یا حذف می‌شوند؟**
صف حداکثر ۵۰ مورد نگه می‌دارد و به ترتیب پردازش می‌شود.

## اعلان مدیریتی گفتگوی آنلاین و تیکت تازه

از نسخه ۱.۷.۰ هر گفتگوی آنلاین تازه و هر تیکت پشتیبانی جدید،
به‌صورت خودکار در **تلگرام و بله** برای مدیران ارسال می‌شود.

### ۱) تعیین گیرندگان

به مسیر زیر بروید:

```
پیشخوان › زرین کد › تنظیمات قالب › ربات و پیام‌رسان › آیدی چت مدیران
```

در این فیلد می‌توانید **چند آیدی** را وارد کنید. جداکننده‌ها
همگی پذیرفته می‌شوند:

```
123456789, 987654321
555555555
444444444;333333333
```

هر آیدی، پیام را هم در تلگرام و هم در بله دریافت می‌کند
(به شرطی که توکن آن پیام‌رسان در تنظیمات ثبت شده باشد).

> **آیدی عددی خود را چطور پیدا کنم؟**
> در تلگرام به ربات `@userinfobot` و در بله به ربات `@bale_userinfo_bot`
> پیام بدهید؛ عدد `id` همان چیزی است که باید وارد کنید.

### ۲) روش دوم: اتصال از پنل کاربری

مدیران و ویراستاران می‌توانند به‌جای وارد کردن دستی آیدی،
از مسیر **پنل کاربری › اعلان‌ها** ربات را به حساب خود وصل کنند
و گزینه‌ی **«اعلان‌های مدیریتی»** را روشن کنند. این گزینه فقط
برای کاربرانی نمایش داده می‌شود که دسترسی مدیریت محتوا دارند.

هر دو روش با هم کار می‌کنند و آیدی‌های تکراری یک‌بار پیام می‌گیرند.

### ۳) روشن و خاموش کردن هر اعلان

| گزینه | مسیر تنظیمات |
| --- | --- |
| اطلاع گفتگوی تازه | تنظیمات قالب › گفتگوی آنلاین › اطلاع گفتگوی تازه در تلگرام و بله |
| اطلاع تیکت تازه | تنظیمات قالب › تیکت پشتیبانی › اطلاع تیکت تازه در تلگرام و بله |

### ۴) نکته‌ی مهم درباره‌ی گفتگوی آنلاین

برای جلوگیری از اسپم، اعلان **فقط با نخستین پیام هر جلسه‌ی گفتگو**
ارسال می‌شود. پیام‌های بعدی همان کاربر اعلان تازه‌ای نمی‌سازند؛
آن‌ها را در صفحه‌ی زیر ببینید:

```
پیشخوان › زرین کد › گفتگوهای آنلاین
```

در این صفحه شمار گفتگوهای خوانده‌نشده کنار نام منو نمایش داده می‌شود
و می‌توانید مستقیماً پاسخ بدهید، گفتگو را ببندید یا حذف کنید.
پنجره‌ی گفتگو هر ۲۰ ثانیه پیام‌های تازه را می‌گیرد.

## اطلاعیه‌های سایت

از نسخه ۲.۰.۰ بخش تازه‌ای به نام **اطلاعیه‌ها** اضافه شده است:

```
پیشخوان › زرین کد › اطلاعیه‌ها › اطلاعیه تازه
```

### محل نمایش

هر اطلاعیه می‌تواند هم‌زمان در چند جا دیده شود:

| گزینه | توضیح |
| --- | --- |
| نوار بالای سایت | نوار باریک رنگی بالای هدر؛ اگر چند اطلاعیه فعال باشد، با بستن هرکدام بعدی نمایش داده می‌شود. |
| پنجره شناور | مودالی که ۱٫۲ ثانیه پس از باز شدن صفحه ظاهر می‌شود. در پنل کاربری، سبد خرید و صفحه پرداخت نمایش داده نمی‌شود. |
| صندوق اطلاعیه پنل کاربری | تب «اطلاعیه‌ها» در پنل کاربر. |

### تنظیمات هر اطلاعیه

- **سبک رنگی:** اطلاع‌رسانی (آبی)، موفقیت (سبز)، هشدار (کهربایی)، مهم (قرمز)، ویژه (طلایی)
- **مخاطب:** همه، فقط کاربران وارد‌شده، فقط مهمان‌ها، فقط مشتریان
- **بازه نمایش:** تاریخ و ساعت شروع و پایان (هر دو اختیاری)
- **اولویت:** عدد کمتر یعنی بالاتر در صف نمایش
- **دکمه فراخوان:** متن و لینک دلخواه
- **قابل بستن:** کاربر می‌تواند ببندد؛ برای کاربران وارد‌شده در پروفایل و برای مهمان‌ها در کوکی ۳۰ روزه ذخیره می‌شود.

### ارسال به تلگرام، بله و پیامک

در همان صفحه‌ی ویرایش اطلاعیه دو گزینه وجود دارد:

- **ارسال در تلگرام و بله** — فقط برای کاربرانی که ربات را به حساب خود
  وصل کرده‌ و اعلان «اطلاعیه‌های سایت» را روشن کرده‌اند.
- **ارسال پیامک** — برای کاربرانی که شماره موبایل ثبت‌شده دارند.

ارسال **یک‌بار و هنگام نخستین انتشار** انجام می‌شود؛ اگر اطلاعیه را
پیش‌نویس و دوباره منتشر کنید، پیام تکراری فرستاده نمی‌شود. برای ارسال
